# Login Form 101

A clean, simple login form built with HTML, CSS and a small amount of JavaScript. This repository contains a single-page example demonstrating layout, styling, and basic client-side validation.

![Login Form Screenshot](./Screenshot%202024-08-08%20221809.png)

## Demo

To preview the form locally:

1. Clone the repository:

   git clone https://github.com/BinaryVortex/Login-Form-101.git
2. Open `index.html` in your web browser (double-click or right-click -> Open with...).

You can also host the page with GitHub Pages by enabling Pages in the repository settings and selecting the `main` branch.

## Features

- Simple, modern form layout
- Clean CSS styling (responsive-friendly)
- Basic client-side validation using JavaScript (inline)
- Single-file, easy to customize

## Files

- `index.html` — the login form markup (contains any small inline JavaScript)
- `style.css` — styles for the form and page
- `Screenshot 2024-08-08 221809.png` — screenshot used in this README
- `beautiful-mountains-landscape (2).jpg` — background image used by the demo (if present)

## Customize

- Edit `style.css` to change colors, spacing, and typography.
- Modify `index.html` to add fields or change the form action.
- Replace the background image with your own image(s) in the repo.
